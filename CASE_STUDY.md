# AI SEO Audit Dashboard — Case Study

## Voice Card

Simple, direct, honest, clear, practical, confident.

## The Problem

I wanted to build a tool that can quickly check a website’s SEO health instead of manually checking different SEO factors one by one. The idea was to give users a structured audit with scores, issues, and recommendations so they can understand what needs improvement.

## What I Did

I built the frontend using vanilla HTML, CSS, and JavaScript because that matched the existing project structure. I organized the dashboard to show the overall SEO score, category scores, technical and on-page results, issues, and recommendations in a clear way.

I also built a separate settings page where users can configure the website URL, crawl settings, SEO quality threshold, focus keywords, competitor URLs, alerts, API settings, and report options. I added form validation, interactive controls, save and reset functionality, and localStorage persistence.

During the AI-assisted workflow, I compared two approaches. The first AI attempt incorrectly generated a JSX file even though the project uses vanilla HTML, CSS, and JavaScript. In the second round, I gave the AI clearer project constraints and file references, which resulted in `settings.html`, `settings.css`, and `settings.js`.

## What Came of It

The result is a working SEO audit dashboard with a dedicated settings page. Users can configure their audit preferences, receive validation feedback, and save their settings for later use.

The biggest thing I learned was that using AI effectively is not just about generating code. I need to check the existing project structure, give clear constraints, and verify the result before accepting it. The second round was more controlled and produced code that actually matched the project architecture.
