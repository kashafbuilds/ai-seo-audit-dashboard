# Project Brief

## AI SEO Audit Dashboard

The AI SEO Audit Dashboard is a production-ready web application that helps users quickly evaluate a website's basic SEO health by entering a URL. The application fetches the website's SEO metadata, including the page title, meta description, and H1 heading, then uses Google Gemini AI to analyze the collected information and generate an overall SEO assessment with technical, on-page, and performance-related scores. It also provides a concise AI-generated summary and actionable recommendations. The project was built with Next.js, React, TypeScript, Tailwind CSS, the Vercel AI SDK, and Google Gemini, with structured API responses, input validation, error handling, accessibility improvements, automated component testing, and production deployment on Vercel.
